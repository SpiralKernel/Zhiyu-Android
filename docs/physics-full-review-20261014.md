## 标注与维护行为

通过项保存作答形式、主/辅助/先备知识、具体题型、逐问答案、独立解法及可观察的评阅依据。难度沿用来源并注明未校准；未核对的年级、学期、课程目标和分值保持未知，不猜填。选择题检查选项字母、整题和小问答案一致；占位答案（包括部分小问仅写“见解析”）、仍有实质疑问或来源类型冲突的记录不能直接放开。

原题、来源答案和原解析保存在历史快照中。作答后展示与双哈希绑定的模型标注解法，避免把已发现有措辞/推导错误的原解析继续展示；不提前泄露答案。模型复核结果不会伪造人工审核记录或数字分数。后续编辑标注会使旧模型审核标记失效；同源重新导入保留审核，来源或题型变化不继承旧结论。

现有63份维护草稿全部保留表单，其中31份只改绑到新来源快照并递增修订号，其余32份逐行不变；新增草稿0、正式发布0。学生界面仍沿用现有数学范围，本轮未扩大学生科目入口。**仅更新本地，未推送 GitHub 或部署云端。**
