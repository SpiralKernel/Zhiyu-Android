# 题目完整标注与判分规则

本规则适用于初中数学及物理，其他学科扩展时沿用共同字段，再增加学科专属标准。教材用于提取阶段学习目标，不需要向学生展示教材正文。

新增[本地AI标定](local-calibration.md)提供无需逐题人工通过的维护流程：模型从受控标签库选ID，双轮盲解和核对结果通过程序检查后可纳入练习。该入口使用`review.status=ai_reviewed`、真实`origin.model`及`difficulty.origin=model`，不伪造`teacher_reviewed`。原人工编辑发布入口仍要求明确人工核对。未知/新增标签候选不注册为正式标签；旧来源标签和问答候选也不会自动进入正式标定标签库。

兼容旧展示的`annotation`中保留规范标签名称；正式标签ID与角色保存在`quality.calibration.tag_ids`，逐小问、方法、错误标签的完整ID与依据保存在绑定的各轮`review_report`。本地AI标定题可进入更新包，但选择题与过程题反馈均保持独立掌握证据权重0。通用证明题仍没有确定性正确性证明器。

## 一题需要记录什么

题目主体继续保存题干、选项、必要图表、来源参考答案和解析。`annotation` 保存版本化结构化标注，协议版本为 `schema_version: 1`，实际字段与校验以 `app/question_annotation.py` 为准。

| 字段 | 内容与约束 |
| --- | --- |
| `response_format` | 单选、多选、填空、计算、证明、应用、综合、简答。这是作答形式，不是学生状态的细题型。 |
| `curriculum` | 来源明确的年级、学期、课程目标、核对依据及状态。未知为 `null`；知识点最低出现册次不能被当作整题适用册次。 |
| `knowledge` | 主要、辅助、前置知识分开。前置知识表示依赖，不代表本题独立测量了它。 |
| `fine_types` | 具体任务和方法，例如“分式方程去分母并验根”，而不是“选择题”“分式”。粗泛候选记录 `fine_type_pending`。 |
| `difficulty` | 1 基础、2 提高、3 挑战，包含来源或判断依据。来源难度未经实测校准，`calibrated` 为 false。不得仅因出现参数或题干较长就断定高难。 |
| `answer_spec` | 答案形式、可接受答案、等价规则、定义域/单位/精度等要求，以及有依据时才填写的单位和容差。规则名称并不意味着后端已经支持任意符号判等。 |
| `parts` | 每个小问独立保存题干、参考答案、解析、知识点、题型、依赖关系、分值、得分点、常见错误。 |
| `grading` | 客观判定、AI 辅助过程评阅或人工复核；整题分值；允许其他正确方法；不确定时必须复核。 |
| `review` | 标注候选/人工已审、答案核验状态、待审问题、生成方法和说明。答案审核与题型审核不能相互替代。 |
| `origin` | 模型和批次。Luna 产出的候选不能自动成为教师审核结果。 |

作答形式兼容旧数据库的 `kind`：选择题仍使用 `single_choice` / `multiple_choice`，其它形式暂用 `reference`，展示形式由 `annotation.response_format` 细分。旧题没有完整标注时继续使用旧流程。

## 小问和得分点

共同材料和完整题干保留在题目主体中。每个小问使用稳定、唯一的 ID；依赖关系只能引用前面的小问。只在真实连续任务标号明确时自动拆问，不能把坐标、运算括号、选项或解析步骤误当小问。

逐问答案不能安全对齐时留空并记录 `part_answer_pending`，不得把整题答案复制给每问。每问标签必须来自该问任务，不能机械复制整题全部知识点。标签不确定记录 `part_tags_pending`。

得分点记录：编号、具体判定依据、应在学生解答中看到的证据、分值。未知分值必须为 `null`，不得为补齐结构发明满分和分配。已填写分值时，小问的得分点分值之和应等于本问分值，全部小问之和应等于整题满分。

例如“一次函数实际应用”可分别标注：建立关系式、代入求值、结合情境求范围。每问再描述变量与单位、等量关系、参数计算、实际定义域等具体依据。参考解法不是唯一路径；正确替代方法也应得分。应用题还需核对单位、取整和实际范围，分式方程要核对分母非零和增根，证明题要核对必要依据。

`common_errors` 描述可观察错误及其关联知识点/题型，例如“去分母漏乘不带分母项”；它是诊断候选，不是对学生习惯或能力的推断。

## 评阅与学情边界

1. 学生填文字或上传照片；AI 转写后给出逐问、逐得分点的反馈，学生核对后保存。
2. 客观选择题沿用已有选项判分。新填空和过程题目前通过文字/图片评阅；任意根式、分段式、证明和开放答案尚无通用确定判分器。
3. AI 的 `part_feedback` 必须引用已有小问 ID；`criterion_feedback` 必须引用已有得分点 ID。已满足或未满足需引用学生转写中的原文；无法核对的反馈标为 uncertain。
4. 仅有人工审核、答案已核验、完整一致的分值、完整逐得分点反馈且证据可核对时，服务端才按得分点累加一个 **AI 建议分数**。候选标注、未知分值、缺少得分点、重复或未知编号、无法识别、评分矛盾均不生成数字成绩。
5. AI 给出的过程评分仍需核对。分数与正误均不自动成为可靠的独立掌握证据。学生更改转写或正误后，旧的过程建议分失效，需重新评阅才能重新生成。
6. 缺图、字迹不清或题目与来源答案冲突时待确认，不能猜测。不能因为缺少某一步文字就推断学生完全不会。
7. 现有可靠学情仍使用独立、经过核验的证据。逐问反馈已可存储展示；逐问证据校准、替代解法评分与通用证明核验仍需继续完善。不能把整道综合题错误分摊给所有知识点。

学生提交前 API 仅返回作答形式和小问题干，不返回参考答案、得分点、常见错误或其他解题提示。提交后的结果和管理员接口可查看完整标注。

## 候选标注、审核与剔除

批量条目使用题号与 SHA-256 绑定来源题干、选项、答案、解析及来源元数据。导入前全量校验，发现来源变化、重复题号、未授权审核状态等则整个批次拒绝写入。应用为新的题目快照，已有作答及评分保留；标签变更不增加同一习题的独立证据次数。

`rule_assisted` 表示 Luna 编写的规则依据来源字段生成候选；`item_read` 表示 Luna 对具体题目逐题细化。两者均不是人工审核，也不代表来源答案完整正确。规则复用不能冒称逐题模型复核。规则提取参考解析不等于完整评分标准，须记录 `rubric_pending`。

用户已要求剔除没有练习价值的内容：明确答案/解析冲突、缺少必要题图/条件、题干残缺、无法确定答案的内容退出练习范围。物理删除会破坏既有作答和来源追踪，因此剔除使用隔离状态和具体原因，后台仍可查。有效的基础题、挑战题和册次待核对题，不仅因简单、难或缺少册次而剔除。

管理员可在“完整标注与大题判分”中修改小问、答案规则、得分点和待审问题；处理全部待审项后，明确确认人工核对再发布。候选批量结果不进入人工审核的离线更新包。源数据再次导入时，内容一致的候选标注与剔除决定保留；来源内容改变后旧候选不能无条件沿用。

## 本地批处理

不调用学生使用的 MiMo/DeepSeek API，不读取学生答卷、账号或 API 密钥。原始分片、全量结果和本地报告保存在被 Git 忽略的 `data/annotations/`，逐题细化样例和可重放生成器保存在仓库中。

```bash
cd /home/sink/AI-teacher
.venv/bin/python scripts/annotate_math_bank.py export --directory data/annotations/math-20261011
.venv/bin/python scripts/luna_math_shard_0.py
.venv/bin/python scripts/luna_math_shard_1.py
.venv/bin/python scripts/luna_math_shard_2.py
.venv/bin/python scripts/reconcile_math_annotations.py
# 先全量检查，默认不写入
.venv/bin/python -m app.manage import-math-annotations --annotations data/annotations/math-20261011/output-*.jsonl
.venv/bin/python -m app.manage backup
.venv/bin/python -m app.manage import-math-annotations --annotations data/annotations/math-20261011/output-*.jsonl --apply
```

三个 Luna 生成器属于本次批次，逐题细化样例按题号和来源哈希绑定，不自动外推到新的题。导出目录已存在的输入文件禁止覆盖，避免覆盖本次审查依据。需要对变化后的题库开新批次时，先导出新目录并调整生成器输入路径/样例，不沿用旧哈希。

## 初中物理扩展

物理标注额外核对单位与量纲、公式适用条件、受力/电路/成像状态，以及实验读数和控制变量的证据。未知册次、分值和容差不可猜填；粗泛规则标签保持 `fine_type_pending`，不能用于精确题型学情或直接进入练习。实验和作图暂通过已有作答形式、具体题型及证据细则表达。来源、实际批次统计与命令见[物理题库标注记录](physics-bank-annotation-20261012.md)。

物理首批精审采用独立复算、交叉核对及最终裁定，修订仅进管理员草稿。源答案未改时保留 `source_only`；拟修复答案/条件未人工确认时用 `unknown`，不能标 `checked` 或 `teacher`。审核台账与Annotation分开，批次原子创建草稿并隔离高风险原题，见[首批复核记录](physics-review-20261014.md)。

物理全量审核要求固定输入、逐题初审和独立复核完整覆盖；分歧及修订以另行哈希绑定的AI裁定记录保留。通过项保存`quality.model_review`并保持`candidate/item_read/source_only`；来源或标注变化不继承旧审核，来源与标注双哈希匹配后才展示结构化独立解法。占位答案、选择题答案不一致、未解决问题和来源类型冲突不能直接放开；未知册次及分值不猜填。全过程不认证为教师已审，不改变现有可信学情门槛，详见[全量审核与入库](physics-full-review-20261014.md)。
