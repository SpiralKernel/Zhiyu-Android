# 当前学生流程与证据规则

## 入口与范围

首次创建本机账号并选择年级学期，第一账号认领旧 demo 记录，后续账号从空白开始。登录后直接进入做题页，恢复或分配当前册次习题。右上角菜单提供练习设置、问 AI、我的学情、学情报告、习题导入、提问记录、外观、账号与题库更新。科目、学段、册次、章节及作答方式在练习设置选择；教材仅给后台提供阶段要求。学生端支持纸感亮色、暖灰暗色和跟随系统，主题与字号在本机保存。

年级学期在服务端筛选题库、讨论、导入材料和报告。切换阶段保留历史记录，切回可继续查看。退出清理页面里的答案、照片和聊天，并撤销服务器会话。账号、图片和学习线索均按学生隔离。

## AI老师与即时求助

无需先做题，可以问知识或拍照问题。题库每道题都有“问 AI”，打开抽屉讨论并保留答案草稿。AI获得当前题干、学生草稿、阶段目标和已有学习线索；未提交时不提供题库标准答案。成功求助后，该题标记为辅助作答，不能计入独立核验题量。失败保留草稿，不保存半份对话、不改变状态。

模型每次可提出最多三项学习观察：正在了解、自述困难、具体困难、引导后理解、理解检查或核对图片答对。后端要求引用学生本轮消息/草稿的原话，绑定引用来源，校验当前阶段及题型；具体错误和理解通过还需独立复核。理解通过必须关联此前检查问题，未知题型可登记为待审核。学习线索写入 `learning_observations`，展示“正在了解 / 待确认 / 需要巩固 / 正在理解 / 待独立验证”。这些线索会影响后续讲解和报告，但不会增加独立核验题量或掌握分。

自由拍照里的学生作答先转写，再由学生编辑核对题干和答案，确认后才用来分析学情；图片上下文在六轮历史窗口之外继续保留。复核失败保留讲解、暂不更新相应状态。详见[AI规则与评测](ai-policy.md)。

提问本身不证明不会；引导后理解也不证明能独立做题。已有困难不会被后续一般提问直接覆盖。学生可点击“记录不准确”撤销某项观察，报告和后续上下文随之重算。对话存入 `teacher_threads` / `teacher_messages`，图片通过有归属校验的私有接口读取。

## 题库与独立证据

七上37个标准题型均有规则核验原创题，25类有基础/进阶起步题，12类暂仅有挑战题。新增11类各有3个子任务；代数式检查一次式恒等、科学记数法检查系数范围及值、近似数检查值及指定小数位数，正方体展开图通过公共边折叠验证。起步题不代表完整覆盖或过程评价。按章节选择，允许挑战时约15%穿插高难题。其它数学阶段以及长文字/拍照题使用来源题库；候选目标映射不代表逐题教师核验。主观题可输入长解答或上传手写照片，先评阅，再核对保存。

可靠练习状态从以下独立证据计算：原创题通过数学规则校验；来源题明确已逐题教师核验并按标准答案判分；无提示辅助；按题目内容哈希去重。同题反复提交保留记录，不凑足五题。对话、导入试卷、AI生成题和AI照片评阅不计入独立核验题量。

| 状态 | 规则 |
| --- | --- |
| 未评估 | 没有独立核验题，已记录的其它作答仍可查看 |
| 证据不足 | 少于5道不同独立核验题，或近期表现仍波动 |
| 需要补强 | 至少5题，最近5题至少错2题，尚不满足稳定条件 |
| 表现稳定 | 至少5题，最近连续3题正确且最近5题至多错1题；累计8题后允许以最近连续3题纠正早期错误 |

五题是尚未校准的保守起步门槛，只影响可靠练习判断，**不限制自由答疑**。不展示能力百分比，“未评估”不表示不会。独立复测后重算状态；结束聊天不会自动判为稳定。历史 `/study/ai/*` 门槛接口保留兼容，新页面统一使用 `/teacher`。

## 导入练习

从右上角“习题导入”上传图片或PDF，选择空白习题/已答试卷；预览后发送识别，逐题编辑题干、学生答案、参考答案及正误，并勾选已核对。已答且明确对错的题形成来源为导入材料的学习线索；空白或无法判断不自动计错。材料按册次保存，删除会撤销相关线索及历史低权重证据。

当前页面导入确认不写旧掌握分；它更新题型学习观察。旧后端兼容的低权重证据逻辑保留，但不参与当前独立核验评分。

## 学情报告

从右上角菜单打开学情报告，自动汇总最近7天、30天或全部记录：题库作答、不同题独立证据、主动提问与核对导入题。章节题型分布展示截至当前状态，练习趋势只用实际作答日期，不编造时长。

AI依据真实记录生成家长分析、关注题型和下一步建议，重点判断须引用同题型的真实证据。按证据指纹缓存，新增作答、提问、导入或纠正后更新。模型不可用时显示规则摘要并允许重试。中文PDF使用相同五色方案，可直接导出。

## 数据与验证

schema9新增 `teacher_threads`、`teacher_messages`、`learning_observations`、`parent_reports`，并给 `imports` 增加册次；保留 schema8 的账号、会话和全部历史作答。真实库升级前在线备份，按原列逐表核对。

密码用随机盐scrypt，会话仅保存SHA-256摘要，Cookie为HttpOnly/SameSite=Strict；HTTPS部署启用Secure。同源校验与身份/阶段限制在后端执行。浏览器验收使用临时库与本地模拟AI，不写入真实学习空间。

## 纸感界面验收

`PYTHONPATH=. .venv/bin/python scripts/browser_paper.py` 使用临时数据库和模拟 AI 验证直接做题、真实题库提交、亮暗主题及系统跟随、字号、320/390px 布局、菜单入口、题图加载/放大/失败重试，以及多问解答/拍照/AI评阅。截图与验证结果位于 `output/evals/paper-ui/`。该脚本不修改真实学生记录。缺失源图片无法通过界面重建；题库原有缺图隔离规则保留。
