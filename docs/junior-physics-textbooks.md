# 初中物理全册教材要求与受控题型（2026-10-22）

覆盖用户提供的人教版八上、八下、九年级全一册，合计22章、92节和入门科学探究，包含12项跨学科实践。九年级在项目中拆为前半、后半进度，物理教材仍只有一本全一册；不把项目建议学期当官方学期边界。

## 实现与来源

- `app/data/physics_textbook_catalog.json`：全部节标题、印刷页/PDF页、固定ID、目标、检查依据、先备要求及可评价题型。目标是项目改写，不存教材正文。
- `app/physics_textbooks.py`：按学习册次返回要求、生成固定细题型，提供可追溯的候选匹配。
- `app/calibration_catalog.py`：157个新增受控细题型接入已有标定协议；模型只能选已有ID。原章节知识ID与已有规则题型ID保留，细题型关联到已有章节目标。数学标签版本不变，物理任务应重新导出，旧物理标定任务不能混用新标签。
- `app/teacher.py`、`app/courses.py`：自由问答与题内求助均得到所选册次的逐节学习要求；不给八年级附带九年级题型。此举不自动认证新题型的掌握度。

来源核对：三本PDF SHA-256与归档清单一致，8页目录已渲染检查，92节首页标题均通过文字定位与项目整理的节标题核对。部分PDF印刷页与文件页的偏移会变化，定位按实际节标题，不以单一偏移换算。未逐页审定教材全文，未据文件名推断版次。原件与全文文字索引保留在私有`data/sources/textbooks/local/`，不随仓库发布。

## 全库覆盖扫描

命令：

```bash
PYTHONPATH=. .venv/bin/python scripts/align_physics_textbooks.py
```

默认只读打开现有数据库，生成私有`data/reports/physics-textbooks-20261022/candidates.jsonl`与`summary.json`，不修改题目年级、答案、标注或学生状态。输入包含3,006道当前物理题，651道隔离题不参加可练覆盖统计；2,355道可练候选中单册候选1,592、跨册候选482、暂无候选281。

这里的“候选”仅来自标签或题干短语证据，没有读取答案解析做归属判断；唯一匹配同样需要语义核对。不能把1,592道说成已审定归册；也不能把零关键词命中说成确实无题。检测到12节无关键词候选，多为实践课，但变阻器、欧姆定律实验、电磁继电器等也需优先核对。

现有双审只核对来源答案及解法，不代表教材归属已审定。剩余455道可练题仍需按本受控库做语义分类，再逐问检查跨章依赖、真实图示及评分依据。此次没有重做独立答案审核，没有校准来源难度，也没有解除651道隔离。

## 评价边界

- 概念题给出条件与现象依据；计算题给出模型、代入、单位和检验。
- 作图题说明对象、方向和对应关系；实验题分别评价变量、操作方案、数据、误差与结论。
- 实践题分开记录目标、方案、过程证据、评价与改进，书面答题不能证明实际制作或操作完成。
- 必要知识与先备项是教学组织建议，不是学生已经掌握的事实。已归册不等于答案正确或足以独立评分。
