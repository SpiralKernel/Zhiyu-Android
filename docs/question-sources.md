TAL 竞赛题的难度数字是来源标签，不等于本项目的基础/进阶/挑战分层。应结合目标年级、所需前置知识、教师审题与真实作答反馈重新映射。

## 导入与复核规则

1. 保留原始题 ID、数据集与版本、下载地址、许可文件、来源原卷、文件哈希和导入时间；禁止覆盖既有历史题快照。
2. 转换题干、选项、标准答案、解析、图形附件、知识点与难度；缺少参考答案或必要图形的题放入待审区。
3. AI 提议知识点/细分题型，优先复用注册表；新类型保留定义、来源与待审状态。
4. 已实现按来源答案判选择题、文字/照片题的 AI 评阅与人工确认。来源题尚未逐题教师审定，教材范围和参考答案仍需复核；缺图或缺答案的题不进入练习。
5. 对题干和来源 ID 去重；抽样复核后按难度、题型与学生证据推荐，避免把竞赛标签当作适合所有初一学生的难度。

导入学生已答试卷是个人学习记录流程，不会自动发布为共享题库。批量适配器已实现；教师审题后台已提供完整标注编辑与人工审核入口。包含多组选项的阅读组合题保留整组文本和分题答案，通过文字/拍照评阅，避免误当一道多选题。
