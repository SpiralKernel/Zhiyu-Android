# 初中数学题库扩充与质检

日期：2026-10-11；规则版本：`junior-math-quality-2026.10.11.2`。

以下记录初次扩充时的结果。当天后续 Luna 完整标注与剔除批次已应用于本地：当前可练习4505题，候选完整结构6361题；见[最新批次报告](math-bank-annotation-20261011.md)。

本轮筛选10,107条初中数学候选记录，去重后保留9,906道当前题目。4,517道同时具备答案、解析、候选细分标签及完整文字材料，进入练习池。“可练习”不代表答案已逐题审定。

当前恢复副本此前没有来源题库数据库，本轮建立数学来源题库，没有恢复或修改旧环境的学生记录。2026-10-08的27,153道全科统计是历史环境记录，不能当作本机当前数量。原始数据、数据库、备份及逐题审核清单位于被Git忽略的`data/`中。

## 标注与课程范围

5,991道题已有候选细分标注，共663种标签。优先保留来源知识点与题型，从知识链提取末级标签，另按明确词语补充解题任务候选。原始标签、难度、答案与解析不覆盖。

- `fine_type_annotations`：标签、来源、匹配依据与待审标记；新增候选全部保留`needs_review`。
- `derived_knowledge_tags`：补充的课程映射候选，与原知识标签分别记录。
- `difficulty_raw/basis`：来源等级及归一化依据。CMM没有题目难度，默认2仅兼容现有接口，明确标为未校准。
- `source_level/grade`：来源年级；没有依据的学期保持空值。
- `curriculum_minimum_grade/book`：根据明确后续知识设置保守的出题下限，不冒充来源学期或教材认证。
- `quality`：规则版本、内容指纹、答案复核方法、结果与待审原因。

663种候选标签不等于663个已审定标准题型。七上37个标准题型与26个原创核验题型保持独立；关键词匹配不能代替逐题确认解题结构，也不证明整册达标覆盖。

## 数学复核与隔离

使用`Fraction`和受限AST解析器检查独立有理数计算、相反数/绝对值/倒数、科学记数法数值与系数形式；将给定方程组答案代回原题检查。未知LaTeX、参数表达式或未支持结构保留未核验，不使用Python `eval`，也不靠模型投票宣称正确。

| 当前题目复核 | 数量 | 含义 |
| --- | ---: | --- |
| 精确规则通过 | 18 | 只通过该规则覆盖的答案条件，解析及题型仍待审 |
| 代回原方程不成立 | 30 | 有数学反例，隔离原题，不自动改写答案 |
| 方程组代回一致 | 11 | 只证明给定值满足条件，不证明完整解集或所有小问 |
| 尚未支持自动复核 | 9,847 | 不表示来源答案正确 |

例如原题`3x−2y=5，4x+y=13`给出`x=3，y=1`，第一式残差为2，因此隔离。来源解析的计算过程不能替代原始方程作为检查依据。

177道题已隔离，原因包括数学反例、答案与解析结论冲突、相同题的来源答案冲突、重复文字选项或原始格式/答案异常。另有3,415道缺图、598道缺解析、3,915道待细分标注，保留资料但不进入练习池。不同原因可重叠，不可直接相加。

CMM常缺第一选项“A.”前缀：仅当首段非空且后续严格为B/C/D时恢复标号并记录修复；缺少内容或选项不连续时不补猜。图像选项都显示占位符时标为缺图待处理，不误报为重复文字选项。不同图像的题不能按相同占位符合并。

## 学生状态与历史

新增来源题保留作答记录，未通过教师审定的答案及细分题型不增加可信独立题量。18道规则答案检查通过也不会自动获得`teacher_reviewed`。来源难度尚未按真实学生正确率校准。

标注升级生成新快照，旧答案、旧标签及已提交作答保留，旧版本退出推荐。历史仍受学生和阶段隔离。同一道来源题换标注版本后再做，不会成为新的独立练习重复加分。重复导入本轮10,107条候选，新增题目为0。

## 可重现命令

```bash
uv run python scripts/fetch_sources.py --dataset math
uv run python -m app.manage backup
uv run python -m app.manage import-bank --dataset math --subject math --stage junior --math-quality
uv run python scripts/audit_math_bank.py
uv run python scripts/export_math.py
```

首次数据库不存在时跳过备份。`--math-quality`联合检查三个来源后按来源入库；单独导入一个来源只能发现当批候选之间的答案冲突。日常扩充数学推荐使用上述联合命令，`--source-root`可指定已有缓存。

逐题待审清单：`data/reports/math-bank-quality.json`，包含题目ID、来源、指纹、问题列表及数学检查结果，不包含学生数据。报告排除旧快照后统计，不将标注升级产生的历史版本计入总量。

下一步优先补图和精确题型审核，再用人工或可靠的独立数学规则扩充可信诊断题；现有七上11个缺少原创核验题的标准题型仍需补齐，不能用来源题量冒充覆盖已完成。
