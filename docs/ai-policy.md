# AI教学规则、证据校验与评测

规则版本：`teaching-guard-2026.10.8-1`。本轮聚焦数学答疑与学情更新，保留schema9、账号及全部历史学习记录。

## 请求的构成

所有AI路径使用 `app/ai_policy.py` 的公共规则与消息构建器：系统消息只包含固定规则，阶段目标、题型目录、题干、答案草稿、历史观察及报告证据放在独立的user角色 `learning_material` JSON里，图片也是user材料。材料中的指令和角色声明不提高权限。历史回答使用正常assistant角色。

自由答疑额外携带当前册次目标、37个七上标准题型（其它册次按当前登记目录）、按当前话题检索的题型记忆（默认8类、最多16类，每类最多3条有效观察和3条练习摘要）、最近6轮讨论，以及上一轮检查问题的消息ID。原始草稿随消息保存，后续不会只记得提问而忘记作答。记忆条目JSON字符预算18,000；学生和册次隔离在检索之前完成，已改善及过期线索不重新放入当前困难提示。

记忆版本为 `student-memory-2026.10.10-1`，与证据复核政策版本分开。记忆读取不构成复习，新错误可以让历史稳定表现进入“待独立验证”，长期未验证进入“建议复测”，均不改写历史分数。详见[学生记忆、衰减与复测](student-memory.md)。

教材当前提供经目录核对后的结构化阶段要求；尚无教材原文检索、引文定位和全文数学正确性认证。图片原件不会在每轮重复发送，模型主要依据核对后的题干和转写；图形细节有疑问时仍须补图/澄清。

## 学情写入链路

1. 授课模型返回讲解、检查问题和最多3条学习观察提议。
2. `observation_guard.py` 校验引用来源、学生实际文字、检查消息ID等必要条件。
3. 对具体困难、引导后理解、理解检查通过、核对图片答对等判断，另发一次独立复核请求；复核不接收本轮授课回复或授课模型的分析结论，只看原始证据、题目、检查问题和题型要求。
4. 仅支持的候选交给 `observations.py` 再校验阶段、目标、题型并入库。保留原话、来源、复核理由、规则版本及检查/图片消息ID。
5. 对话学习线索一律 `independent=false`、`mastery_weight=0`。成功求助仍将当前练习标为辅助作答。

| 观察 | 必要依据 | 结果 |
| --- | --- | --- |
| question_interest | 本轮提问中的真实引用 | 正在了解；使用保守固定描述 |
| self_report | 明确自述困难；排除否定自述与明显他人困难 | 待确认；不等于诊断 |
| difficulty | 实际作答/推理；不能只是问题或自述不会；复核支持 | 需要巩固 |
| guided_success / understanding_check | 当前讨论上一轮检查问题的真实消息ID、本轮实质回答、复核支持；排除简短应答与原样复制解释 | 正在理解 / 待独立验证 |
| reviewed_success | 经过学生核对的图片作答及题干，复核确认本题正确 | 待独立验证 |

引用必须来自指定的 `message`、`student_draft` 或已核对的 `image_answer`，不能把两段内容拼接成证据。来源正确不代表结论正确，额外复核用于减少语义误判。复核中同一候选出现重复决策、引用不匹配、unsupported/uncertain，都不会写入。

只有“懂了/谢谢”等简短应答时，服务端使用简短友好的回应并保留检查问题，防止授课回复口头宣称学生已经理解。其它讲解主要依赖教学提示和模型推理。

导入练习由学生逐题核对正误后，使用 `reviewed_import` 来源记录本题线索，无需再次调用对话复核。它依赖已核对结果，仍不是独立核验题库证据。

## 图片核对与失败处理

自由拍照问题会分开返回 `recognized_question` 与 `transcribed_answer`，并标记清晰/不清晰/无作答。未核对的图片转写不能作为困难或理解的依据；文字里明确表达的兴趣/困难仍可按相应规则记录。

有转写时显示“核对图片中的作答”，学生可编辑题干和答案，点击确认才触发新的分析。服务端绑定本人的当前阶段、讨论、原图片消息及核对后的文字；相同确认重复提交返回原结果，修改已确认内容需新开提问。最新图片题干/核对后的答案在六轮历史窗口以外仍作为上下文保留。

授课请求失败不写部分对话和观察。复核失败时保留已成功的讲解，相关学习状态暂不更新，并在页面说明；不会把失败改成默认通过。若要再次检查可继续提问，暂未实现自动后台重试复核队列。

公共AI调用发送完整JSON Schema，遇到结构错误或明确的token截断最多做1次精简重试，仍失败则报错；结束状态为截断时，即使内容是合法JSON也不接受。网络/HTTP失败不自动重试。旧辅导与试卷识别路径同样拒绝截断，按原流程降级或报错。日志只记录结构字段及错误类型，不记录原始第三方响应、学生内容或Key。独立复核会增加调用耗时和用量，普通知识提问通常不需要额外复核。

当前使用MiMo `mimo-v2.6-flash`，通过兼容接口发送`max_completion_tokens`并关闭短交互思考；原DeepSeek配置兼容。结构验证和结束状态不能保证语义完整、数学正确或教学质量，少量真实样例验收与已知波动见[验证记录](validation.md)。

## 家长报告

统计、章节分布和趋势由程序计算。AI重点困难必须引用真实同题型且可用于薄弱判断的证据：错误作答，或当前规则版本下复核过的困难/已核对导入错误。纯提问、自述和旧的未复核观察不能作为重点困难依据。

数值能力百分比/能力评分会被后端拒绝。报告缓存指纹包含规则版本，旧分析不沿用为新规则下的最新结果。引用有效仍不自动证明文字结论恰当；总述、进步判断和家长建议还需要语义评测。

报告规则另有`parent-report-2026.10.11`版本，单独使分析缓存失效，不改变已保存学习证据的有效性。传给模型的活动事实区分AI提问、题库作答及核对导入，不能把聊天草稿说成题库练习；正文包含内部来源ID或后台字段会被拒绝，实际引用仍保留在结构化字段中。

## 维护与评测

- 固定提示和规则版本：`app/ai_policy.py`。
- 引用/检查约束与独立复核：`app/observation_guard.py`。
- 归属、图片核对、讨论与学习状态：`app/teacher.py`、`app/observations.py`。
- 报告依据与数值限制：`app/reports.py`。
- 可复用样例：`tests/fixtures/teaching_evals.json`；运行器：`scripts/eval_teaching.py`。
- 回归测试：`tests/test_ai_guard.py`、`tests/test_teacher_reports.py`。

```bash
# 默认离线，模拟故意错误的模型输出，验证程序能否拦截
uv run python scripts/eval_teaching.py

# 使用本机配置的模型；有API用量，只创建临时账号与数据库
uv run python scripts/eval_teaching.py --live --limit 8
```

当前16个合成样例覆盖普通提问、自述、负号错误、正确替代解法、简短应答、理解检查正误、改分指令、否定/他人自述、新结构、越阶段、复制解释和图片核对。输出位于被Git忽略的 `output/evals/`，包含回复、实际观察类别、程序检查结果和待人工评价的教学标准，不含Key或真实学生数据。

2026-10-08首次真实模型8例中7例程序检查通过，1例请求失败且未写学情；该例单独复测通过。另复测2例教学语气/实现细节后均通过状态检查。人工查看回复后继续收紧简短应答的措辞，增加服务端固定回应。首轮失败结果与后续复测文件分别保留，没有将结果改写成一次全通过。

## 已知边界

独立复核是同一配置模型的另一次请求，不是不同模型、教师审定或数学证明器。规则中的自然语言识别是保守启发式，会漏记含糊但真实的学习表现。新题型仍主要按规范化名称复用，尚无完整语义合并。

程序测试通过和少量真实模型样例都不代表整体教学准确率；当前样例集中于七上绝对值，必须继续扩展方程、几何、复杂手写和其它年级，并人工核查数学推导、教学语气及证据解释。当前未做大规模能力测验校准。
