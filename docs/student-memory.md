# 学生记忆与复测

实现版本：`student-memory-2026.10.17-1`。入口为 `app/memory.py`，通过学生题型状态、AI老师、家长报告及PDF使用。当前使用可解释规则，不提供未经校准的掌握率或遗忘概率。

## 数据与生命周期

数据库中的独立作答、经过复核的对话观察、已核对导入材料是原始事件。读取时按当前学生和册次重建记忆，不覆盖原始观察，不添加测试事件，也不需要改变schema9。撤回观察、删除导入材料或更新规则后，下次读取即反映变化。

每条观察保留原话、来源ID、创建时间、政策版本和复核依据，并派生：

| 状态 | 含义 |
| --- | --- |
| active | 当前仍有效的线索；具体困难仍不是能力认证 |
| pending | 学生自述困难，待实际作答确认 |
| resolved | 后续不同题的独立正确作答支持已有困难得到改善 |
| superseded | 完全相同的类别和原话已被后续同类记录替代 |
| expired | 超过该类别的有效期，保留历史但不继续当作当前困难 |
| legacy_unverified | 旧政策或缺少独立复核的敏感判断，待重新核实 |
| invalid_time | 缺少有效时区、时间损坏或来自未来的观察，不进入当前诊断 |

不同错误即使属于同一题型也不会互相覆盖。困难只有在其后至少3道不同的有效独立题连续正确，且跨至少2个北京时间日期时，才标为已改善，并保存首次满足条件的作答ID和时间。之后新的错误有自己的依据，不能让已经解决的旧原话复活。

这是保守的题型级改善规则，不代表已验证学生原话中的每一种概念误解。多知识点大题、题型标注偏差和同模板变式仍需更细的证据设计。

## 时间衰减

提问兴趣和自述困难有效7天；引导后理解、理解检查和已核对正确作答有效14天；经过复核的具体困难有效30天。这些是可维护的初始策略，尚未经真实学生数据校准。

到有效期一半时，线索由fresh变为aging、派生可信度降为low；到期变为expired。原始confidence、原话和事件时间不变。`last_confirmed_at`来自有效观察，`last_verified_at`仅来自独立核验题；`retrieved_at`只是AI本次读取时间。反复提问、老师重复讲解、AI读取记录不会重置独立验证时间。

## 独立作答的时间权重（2026-10-17）

题型判断采用最近8条不同、有效、独立的作答，按北京时间日期计算年龄d，每条权重为 `2 ** (-d / 30)`：当天1、30天前0.5、60天前0.25。原作答不修改、不删除，提示作答、同题重复、AI评阅、问答线索不进入这组独立证据。

`evidence_summary`返回加权错误率、有效权重总量、窗口题数和近30天有效独立题数；这些是证据统计，不是掌握评分、能力百分比或遗忘概率。按学习日期计算，避免同一天反复打开导致权重细微变化和报告缓存持续失效。

至少5道不同有效独立题后才判断表现：最近3道连续正确且加权错误率≤0.25，显示表现稳定；最近5道至少2错且加权错误率≥0.30，显示需要补强；其余保持证据不足。修复了旧规则在累计8题后可能仅凭最后3题正确就忽略反复错答的问题。到期复测及新困难线索仍按下节规则改变当前状态。

30天半衰期、窗口和阈值是可维护的初始策略，尚未用真实学生数据校准。时间流逝使证据总权重降低，不把过去正确改写成错误；没有新的作答时，用复测调度表达当前不确定性。

学情面板新增规则说明和逐题型判断依据，可查看对话线索原话并撤回。后端计算所有权重与状态，模型没有修改这些参数的权限。

## 复习调度与学生状态

同题重复、提示作答、AI评阅和导入题不会增加独立证据，也不会延长复习间隔。不同题的独立正确作答在不同日期累积时，间隔按1、3、7、14、30天递增；同一天刷题不推进档位，新的独立错答重置为1天。

该规则是复习任务调度，不是FSRS实现。日后可以用FSRS作为对照，但卡片的回忆概率不能直接解释为数学题型的掌握概率；需要在时间留出的真实独立作答上比较预测校准及复习负担。

`status`保留历史练习表现；到复测时间后，`current_status`显示“建议复测”，不会仅因时间流逝把历史正确改为错误。`review`返回最近验证ID/时间、复测时间和间隔。未验证题型没有虚构的复测时间。题库在允许的章节、题型和挑战设置内优先选最早到期的题型，保留已有未完成题。

历史表现稳定、但出现新的经过复核的具体错误时，当前显示“待独立验证”，历史独立评分不改写；单纯自述或提问不触发这种变化。达到跨天新题改善条件后，再恢复当前稳定展示。

## AI检索与报告

先由 `study.state()`按学生和册次隔离，再检索当前问题。明确题型优先，其次用中文字符片段匹配话题，结合最近独立证据与复测需求排序；有明确相关题型时不拼入无关困难，普通问候最多选4类背景。

默认最多8个题型，上限16个，记忆条目JSON字符预算18,000；每类最多3条有效观察和3条练习摘要。已解决、过期和被替代观察不重新放入当前困难提示。当前采用本地确定性检索，尚不具备嵌入模型对同义表达的语义匹配能力。

家长报告展示当前状态与复测清单；历史事实仍可查看，但只有当前有效、复核合格的错误证据才能支持薄弱项。报告指纹包含记忆版本、生命周期和复测状态，因此即使没有新活动，过期和到期也使旧AI分析失效。旧对话显示派生生命周期，不改写已保存的老师回答。

## 借鉴与验证

- [Graphiti](https://github.com/getzep/graphiti)：有效时间、历史替代与来源溯源。
- [Mem0](https://github.com/mem0ai/mem0)：用户隔离和相关记忆检索。
- [Generative Agents论文](https://arxiv.org/abs/2304.03442)：相关性、时效与重要性排序；模拟环境参数不照搬。
- [FSRS](https://github.com/open-spaced-repetition/py-fsrs)、[Anki说明](https://docs.ankiweb.net/manual/deck-options#fsrs)：独立复习日志与时间相关调度的参考。
- [pyBKT](https://github.com/CAHLR/pyBKT)：后续知识追踪对照模型。

运行 `uv run pytest -q tests/test_memory.py` 验证时间推进、重复/提示排除、同日刷题、错误复发、来源保留、隔离、旧对话、报告缓存和PDF。运行 `uv run python scripts/eval_memory.py` 输出合成时间线到 `output/evals/memory-latest.json`。这些验证程序行为，不证明真实LLM识别准确率、教育效果或已校准的遗忘曲线。
