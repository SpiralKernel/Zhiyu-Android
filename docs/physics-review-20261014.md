## 有实质影响的发现

- 电热水壶题 `a7d2…` 按题给参数得到热效率约 111.8%，数据不可能同时成立；不擅自改某一参数“修到合理”。
- `b45f…` 原答案 ACD 本来包含 D，旧复核记录中“未选D”的说法有误。真实问题是解析误读 B 的“折射和反射”。修复草稿明确修改选项并同步题干、答案和证据。
- `6060…` 的“保持4V”与后来电流变化存在解释分歧。修复稿明确初始状态、温度不变及改变电压；算得原电流 2/3A、电阻 6Ω，不把新增条件伪装成来源已给。
- 热学题 `69bae…` 的“比热容仅取决于物质种类”忽略物态。按字面正确项为 D，来源 BD 被隔离。
- `5108…` 的两项压差已在文字表格中。液面上升 0.015m，与球排水体积比较可推出溢水；球密度应为 2700kg/m³。二审提出的“初始满容器”与液面上升冲突，未采纳。
- `8aef…` 的机械能 15J→13J 允许由空气阻力耗散，不能单凭不守恒判错。修订草稿明确被动力模型，再判先后与下降阶段。
- 试审中发现一份 AI 草稿把酒精水混合液题误配成长度测量题，已全部重建为组分质量与混合密度；另纠正一份选择题把“500N”写作选项答案的错误。
- 月光积水题混用了“迎着月光”和“逆光”；修订稿明确“背着月光”。其他新增条件和舍入依据都记录在台账，不直接覆盖来源。

四道图示题均可从本地来源文字及已转写表格建立修订稿。核对[固定版本的官方目录](https://github.com/SmileWHC/CJEval/tree/590fb8f34239f642324b806b68374c303fe643bf)后，仅找到结果图 `src/overall_results.png`，没有对应题图；本批没有猜造或声称恢复原图。原 `has_missing_assets` 标志保留，材料误报仍需维护者确认。

## 草稿与证据的位置

打开本地 `/admin`，进入“题目标注”，将“题目来源”选为 **维护草稿**、“科目”选为 **物理**。本批新增 63 份待审核草稿，已有草稿未覆盖。新增条件、答案与解析均可编辑，但年级、学期、课程目标、分值仍未知。物理编辑时隐藏七上数学题型快捷选项，避免误套数学标签。

| 文件 | 用途 |
| --- | --- |
| `app/data/physics_review_adjudicated_20261014.json` | 唯一可导入的最终裁定清单，带来源与完整快照双哈希 |
| `app/data/physics_audit_*_20261014.json` | 原始 AI 初审、二审及修订证据；其中保留被指出的错误，**不能把原始输出当最终标注** |
| `scripts/curate_physics_review_20261014.py` | 重放最终裁定，包括纠正初审和二审中的错误 |
| `app/physics_review.py` | 草稿检查、原子隔离与后台草稿入库；不会伪造管理员审核事件 |
| `data/annotations/physics-audit-20261014/review-ledger.json` | 私有逐题完整台账：来源版本、原题、快照、独立解答、差异、剩余问题及草稿 ID |
| 同目录 `local-B0.json`、`local-result.json`、`sample-30.json` | 隔离证据、实际入库验收与 30 道正式试审样本 |
| 同目录 `upstream-tree.json`、`history-check.json` | 固定来源图示查找证据与历史快照保护检查 |

维护命令（默认只检查）：

```bash
.venv/bin/python scripts/curate_physics_review_20261014.py
.venv/bin/python -m app.manage stage-physics-review --annotations app/data/physics_review_adjudicated_20261014.json
.venv/bin/python -m app.manage backup
.venv/bin/python -m app.manage stage-physics-review --annotations app/data/physics_review_adjudicated_20261014.json --apply
```

同一批次重复应用不增加草稿或快照；已应用批次若更换内容会拒绝，需明确建立新批次。首次入库发生任何异常时，隔离和草稿创建整体回滚。当前来源或标注快照变化、人工已审、伪造分值/课程/认证均会拒绝。草稿绑定的是隔离后的当前快照，避免绑定旧版本后无法维护。

审核日期、来源提交、独立解答和修订差异在清单及台账中留存。源答案不变的草稿保留 `source_only`；有答案或条件风险的修订建议使用 `unknown`，均为 `candidate/item_read`，没有 `teacher` 或 `checked`。关闭题型问题不等于认证答案。发布仍需要人工核对、课程依据和明确审批。
