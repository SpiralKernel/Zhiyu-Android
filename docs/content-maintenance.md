# 题库工作台与联网更新

完整标注新增答案规则、前置知识、小问、得分点和待审问题编辑，见[题目标注规范](question-annotation.md)。Luna 候选须逐项核对后发布，已有完整标注不能关闭以绕过审核。

后台入口为 `/admin`。学生端“学习设置”只为获授权的管理员显示工作台链接；后台API独立检查权限，普通学生不能读取题目答案、修改标签或发布更新。后台登录沿用已有账号，会话仍使用HttpOnly Cookie。注册不能自选管理员。

## 授权与使用

在本机项目目录执行；云端对应 `docker compose exec -T app python -m app.manage …`：

```bash
uv run python -m app.manage grant-admin --username 已有账号
uv run python -m app.manage revoke-admin --username 已有账号
```

权限即时生效，不依赖旧会话中的权限缓存。部署者通过维护命令明确授权，本项目不自动把第一个注册者设为管理员。

工作台包括三个页面：

- **数据概览**：学生数、累计作答、来源题数、待审核草稿、各科题量、近14天练习及维护记录；不读取展示学生聊天与照片。
- **题目标注**：按科目、年级、学期、难度、审核状态筛选，搜索题干/题型/编号。编辑题干、长阅读材料、选项、答案、解析、知识点、具体题型、课程目标、难度依据。支持公式预览。
- **题库更新**：冻结已审核内容，生成版本、清单与JSON包，供各端独立更新。

来源题可建立/恢复维护草稿，也可手工新建。`保存草稿`不改变线上题目；`审核并发布`需要人工确认和审核说明，并检查答案与选项、具体题型、课程目标和册次、解析及难度依据。缺失图片的来源题不能仅靠改标签解除隔离；本版尚不支持在工作台补传题干图片。原创规则核验题保留生成器和原始数据，可查看或复制为普通题再审核，普通题不会冒充规则核验题。

编辑器使用修订号避免覆盖另一窗口的修改。每次发布创建新题目ID，旧答案、解析和作答结果保留；同源不同标注版本不会重复增加独立练习证据。若题干/选项/正确答案实质改变，或者维护者撤题，旧版本被标为不再提供可靠证据，报告与当前学情相应重新汇总。选项仅换字母顺序、正确选项内容不变时不使旧证据失效。系统不悄悄重判历史正误；需要新的练习重新确认。普通标签修订仍保留有效历史证据。

## 发布与客户端安装

在线网页直接使用后台已发布题目。离线安装则使用单独的“发布题库更新包”：只有有明确册次/课程目标的人工核对来源题，以及独立规则核验通过的原创题进入包。草稿、未审来源题、缺图题及已撤下题不进入当前题集；包内另带旧版本的撤题/证据失效标记。

协议v1由 `schema_version`、`publisher_id`、单调递增 `version`、`curriculum_version`、题目列表及撤题标记组成。清单带完整包SHA256、题量和时间。相同内容重复发布返回同一版本；旧包冻结，维护后须再次发布才通知离线客户端。SHA256用于完整性校验，发布源身份依赖配置好的HTTPS源和只读凭证，本版没有独立的离线签名体系。

发布端在私有配置中设置至少32字符的随机 `CONTENT_FEED_KEY`；未设置时仍可由已登录管理员下载，匿名访问被拒绝。接收端配置：

```dotenv
CONTENT_SOURCE_URL=https://你的题库服务地址
CONTENT_SOURCE_KEY=发布端的只读更新凭证
```

凭证只存本机后端，不下发网页。客户端学生登录后，在“学习设置 → 题库更新”检查并下载；服务端提供：

| 接口 | 用途与权限 |
| --- | --- |
| `GET /api/v1/content/status` | 登录后查看本机版本，返回时不带更新凭证 |
| `GET /api/v1/content/check` | 登录后检查所配置来源的版本 |
| `POST /api/v1/content/update` | 登录后下载、校验并原子安装题库 |
| `POST /api/v1/content/publish` | 仅管理员冻结并发布更新包 |
| `GET /api/v1/content/feed/manifest` | 管理员会话或只读Bearer凭证获取清单 |
| `GET /api/v1/content/feed/package?version=N` | 同上，按固定版本下载包 |

接收端拒绝重定向、非HTTPS源（回环测试地址除外）、损坏/过大包、同版本被改写、降级版本及不兼容课程版本；完整包上限25MiB，暂不支持分包。先完整下载和校验，后在一个事务内合并，任一步失败回滚，不修改版本指针。远端题有发布源命名空间，不覆盖本机维护题；已撤下远端题退出分配，历史作答与学生状态来源记录保留。重复安装不重复导入。内置原创题与更新中相同题干共用记录，避免重复计分；移除远端题不会删除应用本身自带的相同原创题。

包不包含账号、会话、学习记录、图片上传或API密钥。为支持本地评分，它包含参考答案与解析，只读凭证允许读取这些题库内容；不能将此离线模式当作防止学生提取答案的考试系统。更新范围按发布源全量安装，学生练习仍由本机后端按当前年级学期筛选。

也可下载包与清单后由维护者手动安装：

```bash
uv run python -m app.manage import-content --file 更新包.json --manifest 版本清单.json
```

这是题库更新层，不是安卓打包完成。后续安卓端需要把本地数据库与上传目录放到可持久保存的应用数据目录，复用本协议；AI服务配置和管理员权限不应作为公开APK内置凭证。更新题库不更新Python代码、课程目录或模型规则；课程/协议改变时先升级应用。

数据库版本为11；升级前备份。旧版本10镜像不能直接打开升级后的数据库，回滚须使用兼容版本11的代码或核对并恢复旧备份，不能直接覆盖新学习记录。

相关实现：`app/admin.py`（审核版本）、`app/content.py`（发布/安装）、`web/admin.html`、`web/js/admin.js`、`web/css/bank.css`、`web/css/study.css`。验证：`tests/test_admin_content.py`、`scripts/browser_admin.py`。
