# 安卓离线版

首版为原生Android Activity + 本地WebView + Chaquopy嵌入Python后端。前端、SQLite、题库和学习记录都在手机内运行，不连接云端学习服务。AI调用和用户主动检查题库更新时才联网。应用名为“知域”，图标采用已选定的左右交错分支与粉紫核心。保留原应用ID，覆盖安装可延续旧版数据。

正式包仅含ARM64运行库，支持Android7.0/API24及以上的64位ARM手机与平板；x86_64模拟器使用单独测试包。当前内置6,901道可练题：初中数学3,688、初中物理2,355，高中数学395、高中物理463。题型、册次与答案可信级别沿用现有数据；打包不会把AI候选升级为教师认证。

## 使用

第一次打开先准备离线题库，随后在手机上注册。没有邀请码或云端注册限制；账号不与网站账号自动互通。注册成功后出现AI连接窗口，可以稍后设置，直接离线做题。

菜单中可切换AI连接；设置中的外观提供纸白、陶粉、森林、海盐、淡紫五款配色、暗色/亮色模式、自定义背景/纸面/文字/强调色和字号。账号页可以更换头像，图片会裁成256×256 JPEG并去掉原始EXIF。配色、头像及API连接按本地账号保存。

预设DeepSeek、小米MiMo、通义千问、豆包、Kimi、智谱、硅基流动、OpenAI与自定义兼容接口。模型名称由用户填写；预填值可修改，具体可用模型以自己的账号为准。识图模型单独填写，不把文字模型假定为识图模型。保存连接后可发出一次短请求测试。自定义地址使用HTTPS，不支持关闭证书校验。

API Key只以Android Keystore加密密文保存在手机数据库，接口不会读回明文；浏览器版开发环境使用独立的Fernet密钥文件。不同账号的连接独立。手机内本地HTTP服务只绑定127.0.0.1的随机端口，并以每次启动随机生成的HttpOnly设备令牌保护。WebView不载入外部页面或脚本；官网链接由系统浏览器打开。没有把开发者的API Key、.env、账号库、头像或旧作答记录放进APK。

## 导入题目

菜单「添加题目」进入只读题库与文件导入页面。选择册次和已连接的模型后导入，继续使用现有受控标签、两轮隔离解题、裁定和后端一致性校验，通过项自动纳入手机题库；失败或分歧项保留原因。没有人工审核入口，也不会把新生成题自动当作独立掌握证据。

支持JSON/JSONL、TXT/Markdown、JPEG/PNG/WebP和PDF。图片和PDF需要配置识图模型。安卓PDF由系统PdfRenderer完整渲染，保留向量图、扫描页和版面，不用纯文本提取猜测题图；每批PDF最多4页。图片按页作为一个审核来源，多个题目可能形成综合题；无法完整识别时不入库。只拍题面，避免把参考答案一同交给两轮解题。原有文件限制为最多8文件、单文件12MB、合计24MB、每批最多100个来源题。

任务保存在手机私有目录，主动暂停或系统结束进程后保留检查点，重新打开后可继续。任务绑定提交时选择的连接；切换日常AI连接不会悄悄改变已有任务的审核厂商。删除原连接后需重新建立审核任务。照片选择器同时提供系统相机入口，不申请广泛存储权限。PDF报告通过系统文件保存界面导出。

## 题库更新

「题库更新」主动检查独立的HTTPS签名源：`https://121-40-146-217.sslip.io/mobile-bank/`。这是内容下载接口，不是云端账号或学习记录同步。无网仍可做题；无更新时不会重复安装。

更新清单以独立RSA3072私钥签名，APK中固定公钥，题包核对SHA256及条目数量。安装前备份手机数据库，一个事务只更新题库、索引与课程映射，不替换整个数据库。题干、答案等发生变化时必须提供新题目版本，避免改写旧作答的依据；退出题库的旧题保留历史。用户自己经AI审核加入的题不会被官方题包覆盖。签名、摘要或数据库检查失败则整批回滚。

发布者生成更新包：

```bash
.venv/bin/python scripts/build_mobile_content.py \
  --output output/android/feed --version 2026102502
```

将生成的manifest和对应bank-版本.jsonl.gz一起发布到服务器`/opt/ai-teacher/mobile-bank/`。保留旧包，以便下载中的用户按已取得的版本完成更新。签名私钥在`data/mobile-signing/private.pem`，不进入Git、服务器下载目录或APK；公钥在`app/data/mobile-bank-public.pem`。APK内种子资源改用`.bank`后缀以避免AAPT自动展开.gz，文件内容仍为原始签名对应的gzip字节。

## 构建与维护

可移植构建步骤见[安卓构建与发布](android-build.md)。根目录先用Python3.12执行uv sync，随后下载并验证发行版构建附件，再准备Android资源；不再依赖维护者的本地数据库或签名私钥来打调试包。

默认构建ARM64，模拟器通过`-PmobileAbi=x86_64`独立构建。签名材料、生成资源、设备数据、安装包和原生wheel均被Git忽略。构建准备不会复制.env、账号库或用户上传目录。正式包沿用原签名，覆盖安装保留原数据。

## 0.8.1 界面与答题纸

产品名统一为“知域”。菜单头像位于姓名左侧，整行进入账号页；点击账号头像才打开相册选择与拖动裁剪、缩放。称呼与登录用户名均可修改，用户名归一化并检查唯一性，学生ID不变，历史记录继续归属原账号。安卓系统选择器提供Media picker、Files和Camera，旧系统按可用能力回退；不申请整库照片读取权限，参见[Android Photo Picker](https://developer.android.com/training/data-storage/shared/photo-picker)。

菜单区分“知识掌握”（当前题型状态，图表图标）和“学习报告”（按时间统计与分析，文档图标）；设置页面不再重复放五项分类导航。页头重复的问AI入口已移除，保留题目即时提问及菜单问AI。提问标题和建议随机抽取，建议按当前学科补充。主题覆盖整页及明暗模式；字号为90%、100%、112%、125%、140%，按根字号缩放常用正文、题目、菜单和表单。

所有题目都可通过答题纸图标展开草稿，文字/拍照题额外提供“提交作答”。宽屏横向布局在1100 CSS像素以上左右分栏，否则上下排列；可进一步展开为大答题纸。展开书写时隐藏另一组文字/照片输入，收起后恢复，避免出现两组提交按钮。画布为固定1000×1400逻辑纸面，1500×2100导出，首版没有无限画布或多页功能。

答题纸用Canvas和Pointer Events实现，无新增绘图库：压感调节线宽，曲线平滑，三档笔粗、整笔橡皮、撤销/重做、清空确认。检测到笔后手指用于移动而非落笔，可用手形按钮主动启用手指书写。设备本身的掌触过滤仍影响实际体验，需要真机触控笔验证。

原始笔迹按学生ID、题源和作答ID保存到手机私有writing目录，每笔结束后防抖保存，收起或提交立即保存；断网可用。请求验证作答归属、点数、坐标及笔压范围，草稿保存不修改作答评分或学情。练习形式与章节按册次保存，重启恢复相同练习筛选，当前未提交题目可继续读取原草稿。

提交会导出白底PNG，并与已有文字和最多三张照片交给现有图片评阅接口，仍需核对转写与评价后保存。没有让草稿或一次AI评阅增加可靠独立掌握证据。

最终回归608项通过、1项跳过。Android35模拟器已验证：主题/字号差异、头像裁剪及改名、相册入口、36点/35档压力变化的笔迹、手指接触不增笔迹、PNG导出、覆盖安装保留数据、原生1600×1000平板尺寸双栏及草稿恢复。UI导出测试使用明确标记的评阅响应桩，没有付费调用识图模型；后端图片评阅使用原有模拟提供商回归。截图与测试证据位于output/android/tests-v081。未在实体ARM平板上验证延迟与防误触效果。
