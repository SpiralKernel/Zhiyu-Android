## 本地交付与保护

- `app/question_annotation.py`：严格结构校验、来源指纹、提交前/后数据分离。
- `app/math_annotations.py`：全量校验、事务应用、新快照、幂等导入、剔除旧证据。
- `app/annotation_grading.py`：逐问反馈、证据引用、评分完整性检查与 AI 建议分。
- 学生端：作答形式、填空提示、多问输入、统一拍照、逐问反馈、提交后逐问参考答案。
- 后台：答案规则、主辅/前置知识、小问、得分点、分值、常见错误、审核问题的编辑。
- 更新包：保持候选与人工审核隔离；已有完整标注不能通过关闭标注跳过审核。

应用前 SQLite 备份：`data/backups/20261011-232901-772089.sqlite3`。应用后检查 38 张账号、学习、原创题及其他保留表的行数和内容摘要，均未变化；数据库外键检查无异常，quick_check 为 ok。题库修订不会修改旧答卷与原评分。剔除内容使用隔离和旧证据失效标记，而不是物理删除。

原始分片、全量输出、导入后的逐项报告在 `data/annotations/math-20261011/`，受 `/data/` Git 忽略规则保护。可重放的三个 Luna 生成器、逐题样例和交叉审核修正文件在仓库内。

本轮实现的是 **候选标注与人工维护闭环**。任意证明题的可靠自动判分、所有来源答案的逐题核验、经过实测校准的难度、逐问可靠学情证据仍需后续工作。
